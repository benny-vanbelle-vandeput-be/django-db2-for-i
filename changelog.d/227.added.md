- Database functions write Db2 for i SQL where Django's default does not work: `Length` counts characters (`CHARACTER_LENGTH`), `Log(a, b)` is `LN(b) / LN(a)`, `Concat` treats NULL as empty text, `ATan2` passes its arguments in Db2 for i's order, `MD5`, `SHA1`, `SHA256` and `SHA512` hash the text as UTF-8 (`HASH_*`), and `LPad`, `RPad` and `Repeat` take a NULL argument. `Reverse`, `SHA224` and `SHA384` raise `NotSupportedError`: Db2 for i has no such functions. Django's `db_functions` tests pass on 6.1.
