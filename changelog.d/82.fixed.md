Four queries that Db2 for i refused (#82): `F("x") + None` (the bare `NULL` operand now gets the other operand's type), an annotation of an empty subquery (`Subquery(qs.none())`, now a typed `NULL`), an always-true condition such as `~Q(pk__in=[])` selected together with an aggregate (now `TRUE`, as Django selects it elsewhere), and a `bytes` value for a `BinaryField` (now `VARBINARY(<length>)`, or `BLOB` above 32,740 bytes; it raised `NotSupportedError`). Django's `annotations` and `expressions_case` tests are supported modules now.
