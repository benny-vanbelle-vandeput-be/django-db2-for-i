System check `django_db2_for_i.W001`: a warning when new tables in the library of an alias (`NAME` or `TEST["NAME"]`) would not be journaled, because it has no `QSQJRN` journal and isn't journaled with `STRJRNLIB`. Without a journal, transactions and constraints fail with SQL7008. `django_db2_for_i.W002` means the state couldn't be read. Both can be silenced with `SILENCED_SYSTEM_CHECKS`. `bin/doctor` runs the same check on both test libraries.
