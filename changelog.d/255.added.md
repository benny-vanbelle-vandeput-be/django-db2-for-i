- Tables in another library than `NAME` (#124): `db_table = 'LIB"."TABLE'` (Django's form of a qualified name), or `Meta.db_library = "LIB"` with `"django_db2_for_i"` in `INSTALLED_APPS`. The schema editor qualifies every constraint and index name on such a table with its library (also named constraints inside `CREATE TABLE`), keeps the new name of `RENAME INDEX` / `RENAME TABLE` unqualified, and introspection reads the table's library. Moving a table to another library is refused with `NotSupportedError`. See Configuration, "Tables in another library".
- New system check `django_db2_for_i.E005`: an invalid `Meta.db_library`, or a model that names two different libraries.
