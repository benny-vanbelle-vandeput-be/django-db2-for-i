# Django versions

Supported Django versions, the Python versions we test with each, and the
impact of each version's "Database backend API" changes on this backend.

## Python support (verified from Django's release notes)

| Django | Django's Python support | Our matrix | Source |
|---|---|---|---|
| 6.1 | 3.12, 3.13, 3.14 | 3.12, 3.13, 3.14 | `docs/releases/6.1.txt`, "Python compatibility" |
| 5.2 LTS | 3.10–3.13; 3.14 from **5.2.8** | 3.12, 3.13, 3.14 (requires Django >= 5.2.8) | `docs/releases/5.2.8.txt` |

Django 5.2 support is added in phase 3; phases 0–2 target 6.1 only.
